# Signal log

Five numbers, end of every day. Two minutes.

```
date:
week/day:
hours:                  how long you actually worked, honestly
passes run:             how many of the seven you completed on today's work, /7
tests:                  % of the day's tests passing
stuck events:           how many times you were stuck over 20 minutes
confidence 1-5:         how ready you feel for Friday
one line:               the thing you understand today that you did not yesterday
```

The last line is the one to take seriously. If you cannot write it, that is the most
useful signal in the log and you should still write the line saying so.

Any `SIGNAL` block printed by an `ai/` role goes here too — paste it whole.

---

## Example

```
date: 2026-09-03
week/day: 1/2
hours: 4.5
passes run: 2/7
tests: 100%
stuck events: 1
confidence: 3
one line: 99.99% is four minutes a month, and I had been writing it into documents
  as though it were free.
```
